- **Product Manager:** Roadmap, stakeholder alignment, launch coordination.

- Booking provider integration needs sandbox credentials.
- CMS procurement and access rights must be secured early.
- Potential scope creep with added features (shop, memberships) post-launch.

## Decisions
- Proceed with mobile-first UX approach; desktop enhancements layered after.
- Confirm Tailwind CSS as primary styling foundation.
- Sanity chosen for flexible content modeling.
