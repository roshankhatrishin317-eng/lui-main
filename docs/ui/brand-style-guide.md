# Brand Style Guide — The Lums Charms

## Brand Essence
- **Keywords**: luminous, playful, bespoke, pampering, meticulous.
- **Tone**: Friendly and enchanting while maintaining professional polish.
- **Voice**: Confident, caring, slightly whimsical; use sparkles ✨ sparingly in copy.

## Logo Usage
- Primary logotype in lilac gradient on light backgrounds.
- Use monochrome version (`#2F233B`) on textured or photo backgrounds.
- Maintain clear space equal to the height of the "L" around all sides.
- Minimum size: 120px width on web.

## Color Palette
| Role | Name | Hex | Usage |
| --- | --- | --- | --- |
| Primary | Luminous Lilac | `#BFA2FF` | Buttons, gradients, headings |
| Secondary | Blush Petal | `#FFC7D3` | Background washes, cards |
| Accent | Mint Sparkle | `#A8F0D1` | Hover states, icons, badges |
| Neutral Dark | Charcoal Ink | `#2F233B` | Primary text, nav, icons |
| Neutral Light | Cream Glow | `#FFF6EC` | Background, section dividers |
| Utility | Radiant Gold | `#F5D77B` | Highlights, status alerts |

### Gradient Recipes
- **Hero Gradient**: `linear-gradient(135deg, #BFA2FF 0%, #FFC7D3 50%, #A8F0D1 100%)`
- **Button Hover**: `linear-gradient(90deg, #FFC7D3 0%, #BFA2FF 100%)`

## Typography
- **Display**: `Playfair Display` (weights 500, 600, 700); use for H1–H3 and pull quotes.
- **Body**: `Inter` (weights 400, 500); use for paragraphs, captions, UI labels.
- **Accent Script**: `Great Vibes`; limited to headings or emphasis quotes.

### Typographic Scale
| Token | Size | Line Height | Usage |
| --- | --- | --- | --- |
| `display-hero` | 48px | 120% | Hero headline |
| `display-section` | 36px | 120% | Section headers |
| `title-lg` | 28px | 130% | Card titles |
| `body-md` | 18px | 150% | General copy |
| `body-sm` | 16px | 150% | Supporting text |
| `caption` | 14px | 140% | Metadata, labels |

## Imagery Guidelines
- **Photography**: Soft-focus backgrounds, crisp nail detail, pastel props.
- **Lighting**: Natural daylight or diffused studio light to emphasize sparkle.
- **Composition**: Use hands interacting with accessories, storytelling angles.
- **Salon Interiors**: Showcase charm wall, lounge seating, sterilization areas.

## Iconography & Illustrations
- Line-based icons with rounded terminals, set to 24px grid.
- Use accent pops of `#A8F0D1` and `#BFA2FF` for fills.
- Incorporate starburst and charm motifs as decorative elements.

## UI Elements
- **Buttons**: Pill shape, 56px height on desktop, shadow `0 10px 30px rgba(191,162,255,0.25)`.
- **Cards**: 16px radius, subtle gradient background, hover lift + glow border.
- **Dividers**: Gradient line or dotted motif referencing charms or sparkles.

## Tone & Copy Examples
- Greeting copy: “Hi Lovely, welcome to The Lums Charms—where every detail glows.”
- CTA microcopy: “Reserve Your Glow”, “Charm Me Soon”, “See the Sparkle”.
- Notification: “Your charm session is confirmed. We can’t wait to pamper you!”

## Accessibility Considerations
- Maintain minimum contrast ratio 4.5:1 for text on backgrounds.
- Provide alt text describing visual glam and key design details.
- Avoid using color alone to communicate status; pair with icons or patterns.
